# Desk ダウンロード版

## v1.0.3の変更

- オセロの2人対戦を追加。自動パス・終局・待った・保存復元に対応。
- Zキーで保存後、同じタブをGoogle「英検準2級」検索へ移動（検索時は通信が必要）。
- 将棋とオセロのメニューを統一。右下に対面モードのチェックボックスを配置。
- オセロの合法手の点を手番の色にし、対局中の枚数表示を非表示に変更。

Releases の **Assets → desk.html** を保存し、Chromeなどのブラウザで開いてください。
「Source code」は開発用です。プレイには `desk.html` だけで足ります。

画像・フォント・処理をすべてHTML内に含めています。開いた後の通信や、サーバーの起動、インストールは不要です。
ページ内の操作方法・ルールは通常のWeb版と同じです。

対局は端末のブラウザに自動保存します。ただし、ローカルファイルの保存領域はブラウザの仕様・設定に左右されます。
保存できない場合も対局は続けられます。Web版と対局データを共有する機能はありません。
ファイルの移動・改名やブラウザの変更で、以前の保存を読み込めなくなることがあります。
更新版は改めてダウンロードしてください。自動更新はありません。

管理されている端末では、ファイルのダウンロード・実行が制限される場合があります。利用先の規則に従ってください。

## 開発・公開

`npm ci` の後、`npm run build:standalone` を実行すると `downloads/desk.html` を生成します。
通常版と同じVite設定・Reactコンポーネント・ルールエンジンから生成し、通常の `dist/` は変更しません。
Noto Sans JPのライセンスはHTML末尾に同梱しています。

GitHubのActionsで **Publish downloadable HTML → Run workflow** を実行すると、
テストと単体版のビルドが成功した場合に、新しいReleaseと `desk.html` を公開します。
通常のpushではダウンロード版を更新しません。

1.0.2からバージョン表記を統一しました。`package.json` のversionを更新してから公開し、
Release名・タグを `Desk v1.0.3`・`v1.0.3` の形式にします。同じ版を再公開すると重複タグで失敗するため、変更ごとに版を進めます。
1.0.2の既存タグは、ダウンロードリンクを維持するため `download-2` のままです。
