# Astryx UI比較

ブランチ: `codex/ui-experiment`。比較元は `e37faee`。公開版・Releaseは更新していません。

一覧、将棋メニュー、詰将棋の周辺操作、戦法解説の入口にAstryx 0.7.11を使用します。
対戦コンポーネント、盤・駒台、ルール・保存形式は変更しません。戦法解説は準備中のままです。
その後の依頼により、将棋の対局メニューだけはAstryxへ移行しました。対局中の盤面は維持し、対面モードのチェックボックスは将棋・オセロで共通のCheckboxInputを使用します。
タイトル背景は、1手以上進んだ未終了の保存対局があれば、その盤面・持ち駒・盤の向きを反映します。
その場合だけ「対人対戦 / 続きから」「対人対戦 / はじめから」を表示し、新規対局は確認後に保存を置き換えます。
未着手・全手取り消し・終局済みでは初期配置の背景と「対人対戦」のみを表示します。
新規開始時の状態だけを対戦コンポーネントに渡し、対戦画面の描画は変更しません。
配色はNeutral標準（背景・文字・ボタン・枠線）に揃えています。同梱Noto Sans JP、筆文字タイトルは維持します。

`npm run dev` で比較版を開けます。通常版と単体HTML版のビルド手順は従来どおりです。

## 導入の調整

- Neutralを継承し、フォントとタッチ操作のボタンサイズだけを変更したテーマを対象画面に適用。
- 標準resetは `src/ui/astryx-reset.css` にスコープ付きで同梱。Astryx更新時には元のresetも再確認してください。
- `vite.config.ts` でNeutralのCDNフォントローダーをローカルCSSへ差し替え。Notoは既存の `styles.css` から一度だけ読み込みます。
- CLIの生成テーマモジュールはそのまま利用。doctorの外部Figtree警告はローダー差し替えで対応済みです。
- スタイル境界では既存CSSと一部併用。対戦画面や既存盤面の全面移行は行いません。
- 単体HTMLは約1.7MB（比較元は約1.0MB）。ライブラリの共通CSS・テーマ処理の分だけ増加します。

## 確認

85テスト、型検査、通常・単体ビルド、`astryx doctor --built dist`（エラー0）を確認。
PC・390px幅、一覧からの遷移、問題の切替、正解判定、準備中の表示を確認。
対戦画面の盤・駒台・ツールバー・文字・メニューボタンは、他画面を経由した後も主要スタイルと寸法が比較元と一致しました。

`npm audit` の既存Vitest 4.0.18関連の警告（moderate / critical）はこのUI比較では変更していません。
Vitest UIサーバーは起動せず、テストはrunモードで実行しています。
